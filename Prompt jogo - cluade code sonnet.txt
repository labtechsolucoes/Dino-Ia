Preciso que você crie um clone do "Jogo do Dinossauro do Google" em Python usando Pygame. A arquitetura precisa ser flexível para suportar dois modos distintos:

1. MODO TREINAMENTO (Ambiente RL):
- O jogo não deve depender de inputs do teclado.
- Crie uma classe `DinoGame` com os métodos padrão de Reinforcement Learning: `reset()` e `play_step(action)`.
- O método `play_step` calculará a física de 1 frame e retornará: `state` (distância do obstáculo, altura do obstáculo, velocidade do jogo), `reward`, `game_over` e `score`.
- Este modo deve ser otimizado para rodar em alta velocidade (sem limite de FPS).

2. MODO DUELO (Humano vs Máquina):
- Crie um método adicional chamado `play_versus_mode(ai_predict_function)`.
- Neste modo, a tela deve renderizar DOIS dinossauros simultaneamente (com cores diferentes para diferenciar).
- O Dinossauro 1 será controlado pelo jogador humano (via eventos de teclado no Pygame: Espaço ou Seta para Cima para pular, Seta para Baixo para abaixar).
- O Dinossauro 2 será controlado pela IA treinada (chamando a função `ai_predict_function` recebendo o `state` atual).
- O jogo roda em FPS normal (60 FPS) para ser jogável.
- Se um bater, ele some ou fica translúcido, e o jogo continua até o outro perder. A tela deve mostrar quem ganhou a rodada.

Visual: Geometria limpa e cores contrastantes (retângulos). Não use arquivos de imagem externos, gere as formas no próprio Pygame para facilitar a execução.

Gere o código modular em um arquivo chamado `dino_env.py`. Comente bem o código explicando onde a IA será plugada.
